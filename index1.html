import boto3 import time import json import os athena = boto3.client("athena") DATABASE = "accountspayable" TABLE = "accounts_payable" WORKGROUP = "primary" RESULTS = os.environ.get( "RESULTS", "s3://publictables/practice/" ) MAX_LEN = 500 MAX_ROWS = 500 HEADERS = { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Headers": "Content-Type", "Access-Control-Allow-Methods": "GET,POST,OPTIONS" } def respond(status_code, body): return { "statusCode": status_code, "headers": HEADERS, "body": json.dumps(body) } def sql_string(value): return "'" + str(value).replace("'", "''") + "'" def run_query(query): print("Running Athena query:") print(query) response = athena.start_query_execution( QueryString=query, QueryExecutionContext={ "Database": DATABASE }, WorkGroup=WORKGROUP, ResultConfiguration={ "OutputLocation": RESULTS } ) query_id = response["QueryExecutionId"] while True: result = athena.get_query_execution( QueryExecutionId=query_id ) status_info = result["QueryExecution"]["Status"] state = status_info["State"] if state in ( "SUCCEEDED", "FAILED", "CANCELLED" ): if state != "SUCCEEDED": reason = status_info.get( "StateChangeReason", state ) print("Athena error:") print(reason) raise RuntimeError(reason) return query_id time.sleep(0.5) def insert_record(body): date_of_occurence = ( body.get("date_of_occurence") or "" ).strip() description = ( body.get("description") or "" ).strip() amt_due_raw = body.get("amt_due") payee_comments = ( body.get("payee_comments") or "" ).strip() payer_comments = ( body.get("payer_comments") or "" ).strip() # Required fields if not date_of_occurence or not description: return respond( 400, { "error": "Date of occurrence and description are required." } ) # Validate length if len(date_of_occurence) > MAX_LEN: return respond( 400, { "error": f"Date of occurrence must be " f"{MAX_LEN} characters or less." } ) if len(description) > MAX_LEN: return respond( 400, { "error": f"Description must be " f"{MAX_LEN} characters or less." } ) # Validate amount try: if amt_due_raw in ( None, "" ): amt_due = 0.0 else: amt_due = float(amt_due_raw) except (TypeError, ValueError): return respond( 400, { "error": "Amount Due must be a valid number." } ) query = f""" INSERT INTO {TABLE} ( date_of_occurence, description, amt_due, payee_comments, payer_comments ) VALUES ( {sql_string(date_of_occurence)}, {sql_string(description)}, {amt_due}, {sql_string(payee_comments)}, {sql_string(payer_comments)} ) """ query_id = run_query(query) return respond( 200, { "QueryExecutionId": query_id, "Status": "SUCCEEDED" } ) def get_records(params): search = ( params.get("search") or "" ).strip()[:MAX_LEN] query = f""" SELECT date_of_occurence, description, amt_due, payee_comments, payer_comments FROM {TABLE} """ if search: pattern = "%" + search.lower() + "%" query += f""" WHERE lower(CAST(date_of_occurence AS VARCHAR)) LIKE {sql_string(pattern)} OR lower(CAST(description AS VARCHAR)) LIKE {sql_string(pattern)} """ query += f""" ORDER BY date_of_occurence LIMIT {MAX_ROWS} """ query_id = run_query(query) records = [] paginator = athena.get_paginator( "get_query_results" ) first_page = True for page in paginator.paginate( QueryExecutionId=query_id ): rows = page["ResultSet"]["Rows"] if first_page: rows = rows[1:] first_page = False for row in rows: data = row.get("Data", []) def get_value(index): if index >= len(data): return "" return data[index].get( "VarCharValue", "" ) date_value = get_value(0) description_value = get_value(1) amount_value = get_value(2) payee_value = get_value(3) payer_value = get_value(4) try: amount = float( amount_value or 0 ) except (TypeError, ValueError): amount = 0.0 records.append({ "date_of_occurence": date_value, "description": description_value, "amt_due": amount, "payee_comments": payee_value, "payer_comments": payer_value }) return respond( 200, { "records": records } ) def lambda_handler(event, context): print("EVENT:") print(json.dumps(event)) # Determine HTTP method method = ( event .get("requestContext", {}) .get("http", {}) .get("method") ) # Fallback for older API Gateway events if not method: method = event.get( "httpMethod", "POST" ) method = method.upper() print("HTTP METHOD:", method) # CORS preflight if method == "OPTIONS": return respond( 204, {} ) try: # GET records if method == "GET": params = ( event.get( "queryStringParameters" ) or {} ) return get_records(params) # POST new record if method == "POST": raw_body = event.get( "body" ) if raw_body: if isinstance(raw_body, str): body = json.loads( raw_body ) else: body = raw_body else: body = event return insert_record(body) # Unsupported method return respond( 405, { "error": f"Method {method} not allowed." } ) except Exception as e: print("ERROR:") print(type(e).__name__) print(str(e)) return respond( 500, { "error": str(e) } )
